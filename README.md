# This is supplemental data for our ConfiGen ASE NIER Paper


Jobayer Ahmmed, Myra B. Cohen, Paul Gazzillo, Towards Automated
Configuration Documentation, IEEE/ACM International Conference on
Automated Software Engineering, NIER Track, October 2024
Link to paper: https://dl.acm.org/doi/10.1145/3691620.3695311


Contained are the following files
1. Timing data (in seconds) for each of the tools (Table 2 and Figure 5)
2. Information from ConfiGen about changed files in each version for each of the tools (Table 1 and Figure 4)
3. Graphs for the ratios (Figure 4) for all subjects
4. Example of Doxygen output
5. Example of ConfiGen output
